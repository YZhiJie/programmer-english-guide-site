01 核心词汇体系 ​

本章目标：掌握技术英语词汇的学习方法，拿下第一批 60 个最高频词汇（三个主题组），并能拆解真实报错信息。

1.1 场景导入：为什么背了单词书还是读不懂文档 ​

先看一段真实的文档（摘自 React 官网）：

Strict Mode enables the following development-only behaviors:

  • Your components will re-render an extra time to find bugs caused by impure rendering.
  • Your components will re-run Effects an extra time to find bugs caused by missing Effect cleanup.

如果你在四级词表里背过 strict（严格的）、render（给予、表演）、effect（效果）、cleanup（大扫除），恭喜——每个词都认识，但这段话依然读不懂。因为技术语境下：

  • render = 渲染（组件输出 UI 的过程），不是"表演"；
  • Effect = React 的副作用 Hook，是专有名词；
  • cleanup = 组件卸载时执行的清理函数，不是"大扫除"。

结论：技术英语的核心矛盾不是词汇量，而是「日常词的技术义项」和「技术专有词汇」。 好消息是：技术文档用词高度集中——统计主流开源项目的文档，约 500 个高频词覆盖了 90% 以上的内容。这就是本章要建立的词汇体系。

1.2 方法论：三个原则 ​

原则一：词块（chunk）优先，不背孤词 ​

不要背 deprecate = 废弃，要背 This API is deprecated, use X instead.（这个 API 已废弃，请改用 X）。词块整体记忆，读到时整句理解，不需要逐词翻译。

原则二：在真实语境中记词 ​

每个词至少配一个真实语境：报错信息、文档原句、Issue 评论、Commit message。本章所有例句均取自真实场景。

原则三：按主题分组，建立关联 ​

孤立的词容易忘，成组的词互相提示。本教程把 500 词分为四大主题组：

主题组词量典型场景
编程概念~180读官方文档、教程
调试报错~120看报错信息、Stack Overflow
架构设计~80读 RFC、设计文档
团队协作~120Issue / PR / Review / IM

本章先拿下前三个主题组中最高频的 60 词，其余词量在后续章节随场景滚动补充。

记忆钩子

parameter（形参）与 argument（实参）的区别是文档常客：Parameter 是 Placeholder（占位符，定义时），Argument 是 Actual value（实际值，调用时）。

1.4 主题组二：调试报错（20 词） ​

报错信息是程序员每天读得最多的英文。把这些词拿下，报错阅读速度立刻翻倍。

报错信息高频词 ​

词汇释义真实语料
throw抛出（异常）throw new TypeError('...')
catch / handle捕获 / 处理Uncaught (in promise) TypeError（浏览器控制台）
stack trace调用栈追踪at Object.<anonymous> (/app/index.js:10:15)
undefined / null未定义 / 空值Cannot read properties of undefined (reading 'map')（V8 报错）
reference / reference error引用 / 引用错误ReferenceError: x is not defined
syntax error语法错误SyntaxError: Unexpected token '<'
exceed超出Maximum call stack size exceeded（栈溢出）
invalid无效的Invalid or unexpected token
missing缺失的Missing semicolon.（JSHint）
expected期望的Expected an assignment or function call

排查过程高频词 ​

词汇释义真实语料
reproduce (repro)复现I can't reproduce this on v18.（GitHub Issue）
regression回归（旧功能被改坏）This looks like a regression introduced in v2.3.
workaround临时绕过方案As a workaround, pin the version to 1.2.0.
root cause根因The root cause was a race condition.
debug / troubleshoot调试 / 排障See the troubleshooting guide.
fix / patch修复 / 补丁This patch fixes a memory leak.
deprecate废弃（仍可用但将移除）This method is deprecated since v3.0.
remove移除The legacy API was removed in v4.0.
compatible / compatibility兼容 / 兼容性This release drops compatibility with Node 14.
breaking change破坏性变更⚠ BREAKING CHANGE: the minimum Node version is now 18.（Conventional Commits）

deprecated ≠ removed

deprecated（已废弃）表示还能用，但不要再用于新代码；removed 才是"没了"。升级依赖前务必在 Changelog 里区分这两个词。

1.6 中式英语常见错误 ​

❌ 错误 1：逐词翻译

This function very usefulness.（这个函数很有用。）

✅ This function is very useful. —— usefulness 是名词，此处需要形容词 useful 作表语。中文"很有用"直接映射容易词性错位。

❌ 错误 2：滥用 very / very much

I very like this API.

✅ I really like this API. / I like this API a lot. —— very 不能修饰动词。

❌ 错误 3：中式客套

Please kindly help me review, thank you very much.

✅ Could you take a look? Thanks! —— 技术社区的礼貌是简洁 + 具体，堆砌敬辞反而显得生疏。

❌ 错误 4：直译"提个问题"

I want to ask a question.

✅ 直接问问题本身：Why does X return undefined here? —— Issue/IM 里预告"我要提问"是冗余信息。

1.7 练习（附答案） ​

练习 1：报错拆解 ​

阅读这条真实报错，说出每个部分的含义：

text
TypeError: Cannot read properties of undefined (reading 'map')
    at UserList (/src/components/UserList.jsx:24:18)
查看答案
  • TypeError：错误类型（类型错误）；
  • Cannot read properties of undefined：试图读取 undefined 的属性；
  • (reading 'map')：具体读的是 map 属性——即某个变量是 undefined，却对它调用了 .map()；
  • at UserList (...:24:18)：栈帧，出错位置在 UserList 组件文件第 24 行第 18 列。

修复方向：找到第 24 行调用 .map() 的变量，确认它为什么不是数组（数据未加载？接口返回结构变了？）。

练习 2：选词填空 ​

从本章词汇中选择合适的词填空：deprecated / removed / workaround / regression

After upgrading to v5, the export feature broke — it worked fine in v4. This is a classic ______. Before the official fix, we can downgrade to v4 as a ______. Also note that the old render() API was ______ in v5 and will be ______ in v6.

查看答案
  1. regression（回归：旧版本正常的功能在新版本坏掉）；
  2. workaround（临时绕过方案）；
  3. deprecated（v5 中废弃但仍可用）；
  4. removed（v6 才会移除）。

练习 3：改写中式英语 ​

把这句 Review 评论改写成地道的技术英语：

"这个代码 very good，但是 please kindly 把变量名改一下，thank you very much。"

参考答案

LGTM overall. One nit: could you rename this variable to something more descriptive? Thanks!

要点：用 nit 标记不阻塞的小问题；请求具体（改成什么方向）；礼貌靠 could you + Thanks 即可。

练习 4：词块翻译（中 → 英） ​

  1. 这个参数是可选的。
  2. 这个函数原地修改了数组。
  3. 我本地复现不了这个问题。
查看答案
  1. This parameter is optional.
  2. This function mutates the array in place.
  3. I can't reproduce this issue locally.

练习 5：缩写速答 ​

在 PR 评论里看到 LGTM, just a nit，这句话是什么意思？合并会受影响吗？

查看答案

意思是"整体看没问题（Looks Good To Me），只有一个小瑕疵"。nit 不阻塞合并——改不改看作者，Reviewer 已经放行。
